# Audit temuan UI dan mesin — tahap 1

Tanggal: 11 November 2026. Fokus: menemukan masalah, bukan memperbaiki. Audit ini **belum mencakup seluruh UI atau seluruh mesin**. Pengamatan mesin di bawah diuji dengan Vitest sementara (jsdom), memanggil fungsi aplikasi secara langsung; ini bukan pengujian end-to-end seluruh alur pengguna. Uji sementara dihapus setelah dijalankan, tanpa mengubah mesin. Pemeriksaan browser baru untuk tahap ini gagal karena proses Chromium keluar SIGSEGV, sehingga tidak ada klaim verifikasi visual baru.

Prioritas: P0 = potensi kehilangan/kerusakan artwork atau history; P1 = hasil visual/data salah secara signifikan; P2 = keterbatasan interaksi atau penyimpanan layout. Nomor baris merujuk keadaan kode saat audit.

## Temuan yang direproduksi lewat fungsi/store

1. **P0 — Pathfinder Unite membuang objek terpisah.** Buat dua rectangle 100×100 pada x=0 dan x=200, lalu `performPathfinder([a,b], 'unite')`. Harapan: kedua bagian tetap ada dalam hasil. Aktual: hanya satu hasil dengan x=0, width=100; objek kedua hilang. `src/core/math/pathfinder.ts:412–423` mengambil hanya `res[0]`; `src/state/useStudioStore.ts:2105–2125` menghapus semua input setelah ada hasil. Dampak: operasi di dokumen dapat membuang artwork.
2. **P0 — Pathfinder Divide mengabaikan objek ketiga.** Masukkan rectangle (0,0,100,100), (25,25,50,50), dan rectangle terpisah (300,0,40,40) ke `performPathfinder(..., 'divide')`. Harapan: semua objek diperhitungkan; aktual: hasil hanya pada x=0 dan x=25, tidak ada bagian x=300. `src/core/math/pathfinder.ts:482–500` hanya memakai dua polygon, sedangkan store menghapus semua input. Exclude dan Trim juga hanya memakai dua input menurut pembacaan kode (`:456–458`, `:502–514`); keduanya belum diuji terpisah.
3. **P1 — Minus Front tidak membuat lubang untuk rectangle di dalam rectangle.** Input 100×100 dan rectangle 50×50 pada (25,25); hasil `minus-front` berupa satu path empat titik tanpa fill-rule lubang, bukannya bingkai berlubang. `src/core/math/pathfinder.ts:426–433`. Keterbatasan yang diuji: rectangle axis-aligned, bukan semua bentuk.
4. **P0 — Undo mengikuti history dokumen lain setelah pindah tab.** Buka dokumen A, edit; buka B, edit; pindah ke A; panggil Undo. Harapan: Undo edit A dan tetap di A. Aktual: activeDocumentId berubah ke B dan snapshot B dipulihkan. Membuka/membuat dokumen mereset satu history global (`src/state/useStudioStore.ts:557–603`); pindah dokumen tidak mengganti history (`:627–642`); Undo memulihkan ID snapshot (`:769–785`). Ini juga tampak sebagai bug tab/history di UI; pengujian dilakukan pada store, bukan klik tab browser.
5. **P0 — Duplikasi grup berbagi anak dengan grup asli.** Group dua node, lalu duplicate grup. Harapan: anak baru dengan ID dan parent terpisah. Aktual: array `children` grup asli dan salinan sama persis (`node-hero-hex`, `node-inner-ring` pada fixture). `src/state/useStudioStore.ts:1430–1458` hanya clone node yang dipilih dan mempertahankan referensi anak. Berisiko menyebabkan edit/hapus/ungroup saling memengaruhi; konsekuensi tiap operasi belum diuji.
6. **P1 — SVG import merusak posisi, transparansi, dan warna pada kasus sederhana.** Import `<svg xmlns="http://www.w3.org/2000/svg"><g transform="translate(100,20)" fill="red"><circle id="c" cx="0" cy="0" r="10" opacity="0" /></g></svg>`. Harapan: circle transparan, pusat (100,20), fill diwarisi merah. Aktual node circle x=40, y=40, opacity=1, fill `#000000`; group x=40. Nilai nol diganti default oleh `||` (`src/core/io/svgIo.ts:536`, `:566–575`); transform dan pewarisan atribut tidak diproses dalam contoh ini. Efek terlihat ketika SVG dibuka atau diedit.
7. **P1 — SVG arc berbeda arah menjadi geometri yang sama.** Parsing `M 0 0 A 10 10 0 0 0 20 0` dan `M 0 0 A 10 10 0 0 1 20 0` menghasilkan koordinat dan handle titik yang identik, padahal sweep flag berbeda menentukan arah arc. `src/core/io/svgIo.ts` parser path; file SVG dengan arc dapat berubah bentuk.
8. **P1 — Ekspor SVG dapat menampilkan layer tersembunyi.** Dokumen dengan satu rectangle visible di layer yang disembunyikan dan semua layer lain tersembunyi: `exportDocumentToSvgString` masih menghasilkan `id="a"`. Harapan: artwork di hidden layer tidak diekspor. Aktual: fallback root nodes berjalan ketika tidak ada layer block (`src/core/io/svgIo.ts:248–272`). Kondisi ini spesifik pada tidak adanya block layer yang ter-render. Pola fallback serupa ada pada PDF (`src/core/io/pdfExport.ts:92–108`) dan raster (`src/core/io/rasterExport.ts:130–145`), tetapi output kedua format belum diverifikasi secara visual.
9. **P1 — Image Trace membuat artwork palsu untuk gambar transparan.** Berikan ImageData 10×10 yang seluruh kanalnya nol ke `traceImageDataToVectorNodes`; harapan: tidak ada path atau hasil kosong; aktual: satu path rectangle berwarna `#222222`. Fallback `src/core/io/imageTrace.ts:392–412`. Pengguna bisa mengira hasil trace adalah isi gambar asli.

## Temuan UI/layout dan dugaan yang perlu pengujian lanjutan

- **P2, keterbatasan UI dari inspeksi:** tab dalam floating group hanya menangani klik dan menghentikan pointer down (`src/components/workspace/DockManager.tsx:1192–1197`), jadi belum ada mekanisme memisahkan satu tab floating dengan drag. Penggabungan floating group ke floating group juga belum didukung: pencarian target dibatasi dock group (`:682–715`). Drag dari floating ke dock group sebelumnya sudah diuji, bukan kedua kasus ini.
- **P2, dari inspeksi:** toolbar menyimpan columns, position, order (`src/components/workspace/LeftToolbar.tsx:77`), bukan `tornOffPalettes` (`:664`); palette tear-off berisiko hilang setelah reload atau berganti workspace. Belum direproduksi pada browser tahap ini.
- **P1, dari inspeksi:** SVG export tidak punya cabang khusus image dan jatuh ke path generik (`src/core/io/svgIo.ts:200–244`); raster/PDF juga belum terlihat menggambar image (`src/core/io/rasterExport.ts:148–307`, `src/core/io/pdfExport.ts:145` dan seterusnya). Perlu fixture gambar dan pemeriksaan hasil di browser/PDF sebelum menyimpulkan semua alur image export.
- **P1, dari inspeksi:** jika image gagal dimuat, Image Trace memakai bitmap prosedural (`src/core/io/imageTrace.ts:483–504`) sehingga berisiko memberi hasil yang bukan gambar asli. Belum direproduksi melalui UI.
- **P1, dari inspeksi:** rotasi objek tidak tampak diterapkan sebelum boolean (`src/core/math/pathfinder.ts:24`, `:412`); perlu fixture berotasi dan pembanding geometri.

## Cakupan dan langkah audit berikutnya

Sudah diperiksa sebagian: pathfinder, store/history, SVG, Image Trace, dan pembacaan awal PDF/raster serta layout floating/toolbar. Pada batch sebelumnya 24 panel sempat dibuka tanpa runtime error atau overflow kasar; itu **bukan** pemeriksaan lengkap semua isi panel, semua resolusi/tema, tools, menu/tab, atau semua skenario drag dan preset. Lanjutkan dengan matriks interaksi UI (termasuk floating-to-floating, tab, duplikasi, tema dan viewport), pembuktian ekspor gambar/PDF dan hidden layer, rotasi/kurva Pathfinder, copy-paste grup, penyimpanan/recovery, undo tiap dokumen, dan audit subsistem lain satu per satu. Tidak ada perbaikan mesin dalam tahap ini.
